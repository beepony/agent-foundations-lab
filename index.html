01

模型怎样判断下一步

认识上下文、系统提示词和工具说明：模型只能提出“请帮我做什么”，不能直接操作你的电脑。

02

系统怎样执行工具

理解 Pi 怎样把模型的请求交给 Shell、文件系统等工具，再把真实结果交还给模型。

03

怎样让 Agent 更可靠

理解会话记录、取消操作、输出限制和权限控制，为什么是可靠 Agent 的基本功。
